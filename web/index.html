Usage de l'IA : quatre vues pour quatre publics

Quels outils d'IA sont les mieux évalués ?

Variables : IA utilisée, précision perçue, niveau de satisfaction · Technique : bubble chart

Une bulle = un outil. Position : précision perçue (x) et satisfaction (y) moyennes ; taille : nombre d'utilisateurs ; couleur : outil. Les utilisateurs sans outil renseigné sont exclus. Attention : les axes sont zoomés sur l'intervalle des moyennes ; les écarts entre outils sont faibles (quelques dixièmes de point).

Quels facteurs sont associés à la satisfaction ?

Variables : utilisation par jour, niveau de satisfaction, objectif d'utilisation · Technique : scatter plot

Un point = un utilisateur. Cliquer sur un objectif dans la légende le masque ou l'affiche. Une corrélation n'implique pas une causalité.

Existe-t-il des différences d'adoption entre pays ?

Variables : pays, niveau d'éducation, type d'utilisateur · Technique : heatmap

Attention : le nombre de répondants reflète la composition de l'échantillon, pas un taux d'adoption dans la population du pays. Les répondants sans pays ou sans niveau d'éducation sont exclus.
